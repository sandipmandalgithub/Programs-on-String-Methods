# Java String Methods Programs

This repository contains Java programs demonstrating commonly used methods of the `String` class.

These programs are intended for practicing string manipulation and understanding Java string operations.

## 📚 Concepts Covered

* String length using `length()`
* Character access using `charAt()`
* String comparison using `equals()` and `equalsIgnoreCase()`
* String searching using `contains()`, `indexOf()`, and `lastIndexOf()`
* String extraction using `substring()`
* String modification using `toUpperCase()` and `toLowerCase()`
* Whitespace handling using `trim()`
* String replacement using `replace()`
* Prefix and suffix checking using `startsWith()` and `endsWith()`

## 🛠️ Technologies Used

* **Programming Language:** Java
* **IDE:** Eclipse IDE (if applicable)

## 🚀 How to Run

1. Clone or download this repository.
2. Open the Java source files in Eclipse IDE or another Java IDE.
3. Open the desired Java class.
4. Run it as a Java Application.
